## 1. 多边形不是像素近似

三角形和正方形由 `TriangularPolygon` 表示，顶点保存为三角 Bravais 基底 `(a1,a2)` 中的分数坐标。
程序先在真实笛卡尔坐标中按外接半径和旋转角构造正多边形，再求解

```text
[a1 a2] [u;v] = [x;y]
```

得到各顶点 `(u,v)`。对任意倒格阶数 `(m,n)`，多边形的形状变换为

```text
I_mn = integral_P exp[i 2*pi*(m*u+n*v)] du dv
```

代码用散度定理把面积积分转为每条边的解析积分。它不会产生栅格锯齿和 FFT 像素误差；平移、旋转、
顶点朝向和面积都会真正改变介电常数 Fourier 系数，随后重新进入 `Cb+Cr+Ch` 六波矩阵。

理想尖角会包含更强的高阶 Fourier 分量。真实刻蚀通常存在圆角，因此多边形候选必须再扫描圆角半径，
并用 RCWA/FEM/FDTD 验证。当前解析多边形代表理想几何上限，不代表实际 SEM 孔形。

## 2. 本轮搜索范围

共定义并通过周期邻胞重叠检查的 30 组候选：

| 形状族 | 扫描内容 |
|---|---|
| 全椭圆 | 孔距、主孔椭圆率、副孔半径和副孔椭圆率 |
| 椭圆主孔 + 三角副孔 | 三角形外接半径、孔距、朝内/朝外/平行方向 |
| 三角主孔 + 椭圆副孔 | 主三角形尺寸、旋转角和副孔距离 |
| 全三角孔 | 主副孔尺寸、距离和朝向 |
| 椭圆主孔 + 方形副孔 | 方形尺寸、距离和菱形方向 |
| 方形主孔 + 椭圆副孔 | 主方孔尺寸和旋转角 |

所有候选总填充率保持约 `0.15`，以减少“只是空气占空比不同”造成的混淆。搜索分三级：

1. 30 组粗筛：`D=4`、纵向步长 `6 nm`、有限网格 `N=4`；
2. 总榜前四名，加每个多边形形状族最佳代表，共 9 组中等精度复排：`D=7`、`4 nm`、`N=7`；
3. 总榜前两名，加最佳多边形代表，共 3 组最终复算：`D=10`、`3 nm`、`N=(7,9,11)` 外推。

这种分层晋级避免了椭圆候选数量较多而挤掉所有多边形，也避免直接把粗网格排名当成结论。

## 3. 最终结果

### 3.1 综合光束质量最佳：三椭圆

最终综合评分最高的结构仍是上一轮径向三椭圆：

```text
main: center=(0,0), radii=(0.18120a,0.15756a), angle=90 deg
sat1: center=(0.32,0), radii=(0.09466a,0.06761a), angle=-30 deg
sat2: center=(0,0.32), radii=(0.09466a,0.06761a), angle=+30 deg
```

| 指标 | 三椭圆最佳值 |
|---|---:|
| 最低阈值模式 | A |
| 阈值 | `57.06 cm^-1` |
| 中心/峰值 | `1.000` |
| 峰值偏移 | `0.000 deg` |
| 质心偏移 | `0.010 deg` |
| 椭圆率 | `1.038` |
| `1 deg` 内功率 | `77.18%` |
| 最近模式间隔 | `21.88 cm^-1` |
| 综合分数 | `97.57` |

把副孔椭圆率从 `1.4` 增到 `1.7` 后，阈值变为 `59.63 cm^-1`，`1 deg` 内功率降到
`73.22%`，综合分数为 `96.80`。所以各向异性不是越强越好。

### 3.2 低阈值备选：三角主孔 + 椭圆副孔

最佳多边形候选为 `triangle_main_d38_r20_a000`：

```text
main: equilateral triangle, center=(0,0), circumradius=0.20a, angle=0 deg
sat1: ellipse, center=(0.38,0), radii=(0.13178a,0.09413a), angle=-30 deg
sat2: ellipse, center=(0,0.38), radii=(0.13178a,0.09413a), angle=+30 deg
```

主三角孔填充率 `0.06`，两个副孔各 `0.045`，总填充率仍为 `0.15`。

| 指标 | 三角主孔备选 |
|---|---:|
| 最低阈值模式 | D2 |
| 阈值 | `24.00 cm^-1` |
| 中心/峰值 | `0.980` |
| 峰值偏移 | `0.150 deg` |
| 质心偏移 | `0.023 deg` |
| 椭圆率 | `1.052` |
| `1 deg` 内功率 | `78.06%` |
| 最近模式间隔 | `7.00 cm^-1` |
| 综合分数 | `91.01` |

它的阈值比三椭圆低很多，主瓣也很干净，但不是严格法线峰值，而且与 A 模只相差约
`7 cm^-1`。加入制造误差、热漂移和空间烧孔后更容易发生模式切换。因此：

- 若优先追求严格法线、模式稳定和圆对称光斑，选三椭圆；
- 若优先追求低冷腔阈值，并允许小角度校正，三角主孔值得继续连续优化。

## 5. 新的设计经验

1. **位置相位仍比形状名称更关键。** 三角/方形副孔在原椭圆的 `0.32a` 距离附近表现较差，移到
   `0.36a-0.38a` 后才恢复中心亮斑。不能把圆孔直接等面积替换成三角孔而保持所有位置不变。
2. **尖角可大幅改变模式排序。** 三角主孔把最低阈值分支从 A 改成 D2，并把阈值降到约
   `24 cm^-1`；这是其最有价值之处，也是模式竞争风险的来源。
3. **全多边形不如混合孔形稳定。** 本轮全三角孔的偏轴和模式间隔都较差。保留两个平滑椭圆副孔，
   只让主孔承担强 Fourier 扰动，效果更好。
4. **等填充率不等于等光学作用。** 相同面积的三角形具有更大的外接半径和更强高阶谐波，必须同时
   调整孔距、旋转角和截断阶数。
5. **低阈值与稳健单模存在权衡。** 三角主孔阈值更低，但最近模式间隔只有三椭圆的约三分之一。
6. **加工圆角可能改变结论。** 三角形顶点的圆角会削弱高阶 Fourier 分量，必须把圆角半径作为下一轮
   参数，而不能直接用理想尖角结果流片。
7. **综合分数不是自然常数。** 当前评分偏重法线、圆度、包围能量和模式间隔。若应用更重视低阈值，
   应改变评分权重，此时三角主孔可能成为首选。
