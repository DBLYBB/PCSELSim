# Liang 第四章与 Inoue 2019 仿真模型的关系

> 2026-10-08校对提示：本文保留早期教程/推导和历史结果；最新修复、可信度与设计评价以
> [本轮总审计](research_design_audit_20261008_zh.md)为准。旧“最佳”、精确阈值、单模及易加工
> 判断未经最新收敛/工艺验证时不得直接引用，能带是近Γ局域片段，远场能量对评估视窗归一化。

## 1. 先给出结论

当前两套程序不是完全相同的数值求解器，但属于同一个四波耦合波理论框架。

- 两者使用相同的四个基本波：

  ```text
  Phi = (Rx, Sx, Ry, Sy)^T
  ```

- 两者使用相同的 A/B/C/D 正交带边基底；Liang 脚本直接导入
  `src/pcselsim/coupling.py` 中的 `band_edge_basis()`。
- 两者都用复数 4x4 耦合矩阵 `C` 描述面内反馈、模式频率和垂直辐射损耗。
- 两者使用相同的有限区域单向入射边界思想：

  ```text
  Rx(0,y) = Sx(L,y) = Ry(x,0) = Sy(x,L) = 0
  ```

- Inoue 主平台求解含载流子、增益饱和和空间烧孔的时域非线性问题。
- Liang 第四章脚本主要求解无源/阈值附近的频域线性本征值问题。

因此，准确的说法是：**物理骨架相同，状态变量和耦合基底相同，但目前的求解后端、参数来源和可计算物理过程不同。**

## 2. 共同的物理模型

### 2.1 四个慢变基本波

方形晶格第二阶 Gamma 点附近显式保留四个面内传播波：

| 分量 | 传播方向 |
|---|---|
| `Rx` | `+x` |
| `Sx` | `-x` |
| `Ry` | `+y` |
| `Sy` | `-y` |

高阶空间谐波和垂直辐射波不作为独立的时空数组保存，而是通过耦合系数进入 `C`。

### 2.2 共同的 A/B/C/D 基底

两套代码共享：

```python
from pcselsim.coupling import band_edge_basis
```

其中四列分别代表 A、B、C、D 带边模式在 `(Rx,Sx,Ry,Sy)` 中的线性组合。
Liang 脚本没有复制另一份不同的模式定义，因此 A/B/C/D 的命名和相位约定与 Inoue 平台一致。

### 2.3 共同的耦合矩阵形式

两者都使用：

```text
C = V diag(delta_A+i alpha_A, ..., delta_D+i alpha_D) V^H
```

其中：

- `V` 是 A/B/C/D 基底矩阵；
- `delta` 表示带边频率偏移；
- `alpha` 表示辐射损耗；
- `Im(C) >= 0` 对应被动腔中的能量衰减。

矩阵来源必须区分三个入口：Inoue 基准使用 `configs/inoue2019.yaml` 中的校准值；旧的 Liang
逐图教学入口保存 CC、ET 和 RIT 的论文校准值；新的自定义半导体入口则从晶胞 Fourier 系数、
纵向 TE0 模和 Green 函数直接计算 `C1D + Crad + C2D`。后者改变几何后会重新生成 `C`，并把同一
矩阵同时交给有限区域和时域求解器。

## 3. 两套方程的数学关系

### 3.1 Liang 第四章：频域本征问题

Liang 式 (4.21) 为：

```text
(delta + i alpha) Phi = C Phi + i D Phi
```

其中：

```text
D Phi = (dRx/dx, -dSx/dx, dRy/dy, -dSy/dy)^T
```

本征值的实部给出频率偏移 `delta`，虚部给出阈值增益/损耗 `alpha`。这是一个线性、稳态、
有限区域的非厄米本征问题。

新脚本中的对应代码是：

```text
LiangFiniteAreaModel.operator()
LiangFiniteAreaModel.solve_band_edges()
```

空间导数使用有限差分，使用 SciPy ARPACK 稀疏本征求解器寻找 A/B/C/D 附近的本征值。

### 3.2 Inoue 2019：时域非线性问题

Inoue 主平台求解的光场结构可写为：

```text
dPhi/dt = -vg D Phi + i vg C Phi
           + vg(g-alpha_in)Phi/2
           - i vg Delta_delta(N) Phi
           + spontaneous_noise
```

并与载流子方程自洽耦合：

```text
dN/dt = J/(e d_active) - N/tau
        - vg g_active(N) U
        + diffusion * laplacian(N)
```

代码对应：

```text
src/pcselsim/solver.py::TimeDomainSolver
```

数值方法包括：

- 二阶 Lax-Wendroff 定向传播；
- 局部耦合矩阵指数；
- Strang splitting；
- Heun 载流子时间推进；
- 增益饱和、载流子扩散、折射率变化、自发辐射噪声和空间烧孔。

### 3.3 为什么说它们属于同一理论

对 Inoue 时域方程作以下限制：

1. 关闭电流注入、载流子动力学和随机噪声；
2. 把增益和损耗视为线性常数；
3. 假设谐波时间依赖；

   ```text
   Phi(x,y,t) = phi(x,y) exp(i vg delta t)
   ```

4. 把时间微分移到方程左侧；

即可整理为 Liang 式 (4.21) 的频域本征形式。换言之，Liang 本征问题是 Inoue 时域方程在
无载流子、线性阈值分析条件下的稳态版本。

## 4. 当前代码没有完全共用的部分

### 4.1 数值离散不同

| 项目 | Inoue 主平台 | Liang 第四章脚本 |
|---|---|---|
| 求解域 | 时间 + 二维空间 | 二维空间本征值 |
| 主求解器 | Lax-Wendroff + Strang split | 稀疏矩阵 + ARPACK |
| 边界实现 | 每个时间步令入射波为零 | 本征矩阵中的虚数边界罚项 |
| 载流子 | 有 | 无 |
| 增益饱和/空间烧孔 | 有 | 线性阈值模型中无 |
| 随机噪声 | 可选 | 无 |
| 输出 | 时间轨迹、功率、近场、频谱 | 本征频率、阈值、模式包络、远场 |

Liang 论文使用交错网格有限差分。旧教学脚本使用中心差分和边界罚项；新的自定义半导体入口使用
带零入射 ghost cell 的一阶迎风离散，并对多个网格的本征值按 `1/N` 外推。它仍不可能与作者未公开
程序逐元素相同，因此必须保留网格收敛检查。

### 4.2 参数来源不同

两篇论文没有公开实验器件完整三维结构生成的全部复耦合矩阵。因此：

- Inoue 的 `C` 是按 Inoue 2019 图表校准的；
- 旧 Liang 逐图脚本的 CC/ET/RIT 曲线仍包含按第四章数据校准的部分；
- 自定义半导体脚本的 `C` 不使用表 4.2 阈值作输入，而由用户定义的单孔/多孔理想直壁晶胞和层结构计算；
- Inoue 真实 SEM 器件仍不是作者未公开生产矩阵的逐元素恢复。

当前默认自定义晶胞是 Inoue 图 2(a) 的理想化双椭圆，中心沿 `x,y` 同时相差 `0.25a`。
该几何算得 A 模最低；这项排序来自几何矩阵，不是事后交换 A/B 标签。孔半轴和三维轮廓并未由论文
唯一给出，所以仍需作者 SEM 数据或独立 RCWA/FEM/FDTD 才能作严格定量验收。

## 5. 两套代码目前如何连接

```text
  user geometry -> epsilon_mn -> vertical TE0 -> C1D + Crad + C2D
                                              |
                         +--------------------+--------------------+
                         |                                         |
              finite-area eigen solver                    TimeDomainSolver
                         |                                         |
             thresholds / fields / FFP              carriers / SHB / spectra
```

自定义半导体入口已经让两个求解器共享同一个几何派生矩阵。Inoue 2019 基准和旧 Liang 逐图入口仍
保留独立校准参数，以免把缺失的实验几何伪装成已知量。

时域入口还会把最低阈值模作为复场投影，并减去该模的公共实失谐后积分；绘谱时再恢复物理参考频率。
这个旋转参考系只改善采样，不改变 `Im(C)`、功率、阈值或模间频差。

## 6. 后续建议的统一方式

目前已经完成“几何生成统一 `C`，频域和时域共用”的核心重构。下一步的严格化顺序是：

1. 用二阶或交错网格离散替换一阶迎风，并做可重复的 Richardson 外推。
2. 实现 Liang 广义 Green 函数，把倾斜孔壁、顶底界面反射和复数材料色散纳入 `Crad/C2D`。
3. 三角晶格六波 `Cb+Cr+Ch`、能带、六方向有限腔、包络和矢量远场已经单独实现；下一步是
   Liang 式 (5.18) 原始 staggered generalized mass matrix 的独立交叉实现，以及六波载流子时域。
   它没有使用方形四波有限腔代替。
4. 以 RCWA/FEM/FDTD 的本征频率和 Q 值作独立交叉验证，而不是拿同一篇论文的结果反向拟合。
5. 全固态迁移已有 `run_geometry_derived_ybyag_pcsel.py` 薄膜导模原型；当前500 μm假设被判定增益
   不可达。下一步是用真实可制造层栈、泵浦俘获和热模型替换原型，而不是套用半导体增益。

统一后的推荐工作流是：

```text
geometry -> vertical mode -> coupling C
                         -> finite eigen solver -> threshold/modes/FFP
                         -> time-domain solver  -> turn-on/SHB/multimode
```

## 7. 使用时如何选择

- 研究论文逐图含义：使用 Liang 第四章教学脚本。
- 研究自定义方形晶格器件的长度、阈值、A/B 模式和远场：使用自定义半导体脚本。
- 研究电流开启过程、弛豫振荡、载流子分布、空间烧孔和高电流多模：使用 Inoue 时域主平台。
- 研究同一自定义结构从阈值到高电流的全过程：自定义半导体脚本已把同一个 `C` 送入两个求解器；
  仍需分别检查频域网格、时域网格和时间窗收敛。
