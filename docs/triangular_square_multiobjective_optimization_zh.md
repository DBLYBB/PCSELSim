## 2. 三角晶格：38 组局部细化

所有候选总填充率固定为 `0.15`。扫描主三角孔外接半径 `0.18a–0.22a`、主孔旋转角
`-30°–30°`、副孔中心半径 `0.34a–0.45a`、两个副孔相对夹角、椭圆率 `1.1–1.8`、椭圆长轴方向，
以及三角副孔朝内/朝外/切向。38 组粗筛后保留 6 组复排，3 组最终使用 `N=(7,9,11)` 外推。

### 2.1 推荐的稳健折中：三个三角孔

`triangle_sat_08` 的几何为：

```text
主孔：等边三角形，外接半径 0.21a，旋转 15°，面积 0.06615 A_cell
副孔：两个等边三角形，各面积 0.041925 A_cell，朝向晶胞中心
副孔中心：距原点 0.44a，物理方位角 -24° 与 +24°
```

| 指标 | 数值 |
|---|---:|
| 最低阈值模式 | `D2` |
| 总阈值 | `21.01 cm^-1` |
| 最近模式间隔 | `18.10 cm^-1` |
| 中心/峰值 | `1.000` |
| 峰值偏移 | `0.000°`（远场图像细采样约 `0.05°`） |
| 质心偏移 | `0.0074°` |
| 椭圆率 | `1.047` |
| `1°` 包围能量 | `83.20%` |
| full RMS 发散角 | `1.58°` |

与上一轮 `24.00 cm^-1` 的三角主孔结果相比，总阈值降低约 `12.5%`，最近模式间隔由约
`7.00 cm^-1` 增大到 `18.10 cm^-1`。三角副孔的价值不只是降低损耗，还把竞争模推远。

### 2.2 追求更低阈值：三角主孔 + 椭圆副孔

`distance_+0.420` 使用外接半径 `0.20a`、角度 `0°` 的主三角孔，以及距离 `0.42a`、椭圆率
`1.4` 的两个径向椭圆副孔。总阈值为 `20.31 cm^-1`，`1°` 包围能量 `84.60%`，中心峰仍在法线，
但模式间隔降到 `9.14 cm^-1`。若更看重最低阈值，可优先验证该结构；若看重制造误差下的单模
稳定性，则优先三个三角孔。

### 2.3 参数影响总结

1. **副孔位置最敏感。** 对本层栈和填充率，`0.40a–0.44a` 明显优于原来的 `0.38a` 附近。
2. **椭圆率存在平台而非单调最优。** `1.1–1.6` 较稳健；到 `1.8` 容易发生模式排序切换。
3. **椭圆长轴小角度旋转是次级变量。** `±20°` 的影响小于孔距和主孔尺寸。
4. **三角副孔朝向很关键。** 朝内组合把模式间隔显著拉大；等面积朝外/切向并不等价。
5. **主孔旋转并非越大越好。** `15°` 只有与 `0.44a`、内向副孔和收窄后的副孔夹角共同出现时
   才形成最佳组合。
6. **低阈值与稳健性仍有权衡。** `20.31 cm^-1` 是最低阈值方案，`21.01 cm^-1` 则以约
   `0.70 cm^-1` 的代价把模式间隔几乎翻倍。

## 3. 方形晶格：24 组跨拓扑筛选

方形搜索保持总填充率约 `0.05`，比较中心圆/椭圆、平衡双椭圆、Inoue 式非对称双孔、沿
`+x/+y` 的三孔、五孔十字、三角主孔、三角副孔、方形主孔和四三角旋翼。24 组粗筛后对 10 组
复排，最终 2 组使用 `N=(13,17,21)` 外推。

公共四波 `LinearMode.alpha` 按既有约定只含几何矩阵中的垂直辐射和开放边界的横向逸出，因为
时域阈值电流审计会另加材料内损耗。为与六波总损耗表采用同一口径，本优化脚本在生成搜索 CSV、
阈值图和最终模式表时再加一次 `internal_loss_cm=5`；公共求解器不变，也不会在时域审计中重复计数。

### 3.1 推荐的稳健折中：45° 三角主孔

`triangle_main_a045`：

```text
主孔：中心等边三角形，面积 0.024 A_cell，外接半径约 0.1359a，旋转 45°
副孔：+x、+y 各一个径向椭圆，中心距 0.27a，各面积 0.013 A_cell，椭圆率 1.4
```

| 指标 | 数值 |
|---|---:|
| 最低阈值模式 | `A` |
| 总阈值 | `11.87 cm^-1` |
| 最近模式间隔 | `1.46 cm^-1` |
| 中心/峰值 | `1.000` |
| 峰值偏移 | `0.000°` |
| 椭圆率 | `1.0002` |
| `0.5°` 包围能量 | `99.67%` |
| `1°` 包围能量 | `99.94%` |
| full RMS 发散角 | `0.255°` |

它是当前方形搜索中最圆、最窄且通过模式间隔门槛的候选。方形器件边长为 `300 um`，三角有限
器件当前半径仅 `30 um`，因此方形结果更窄、横向逸出损耗更低并不意外。两套搜索适合在各自晶格
内部比较候选，但绝对阈值和发散角不能直接当作相同口径的方形—三角胜负；严格比较必须先统一
器件口径/边长、泵浦区和边界。

### 3.2 数字最低但不推荐直接流片：三椭圆

`triple_xy_d20_sf08` 的最低 B 模总阈值仅 `6.46 cm^-1`，中心峰和圆度也很好，但 A/B 模只差
`0.122 cm^-1`。该间隔远小于典型加工、温度和载流子引起的漂移，因此实际最低模很可能翻转或双模
竞争。脚本把它标记为 `acceptable=False`；“balanced” 数学评分仍保留它，是为了展示阈值极限，
并不等同于工程推荐。

### 3.3 方形晶格经验

1. 中心单圆孔、中心椭圆和平衡十字孔虽然损耗较低，但最低 A 模保持法线暗心，不适合作为中心亮斑。
2. 打破 `+x/-x`、`+y/-y` 完全平衡后，三孔和三角主孔可以把最低模变为中心亮分支。
3. 三孔能把总阈值压得很低，却容易造成 A/B 近简并；主三角孔牺牲部分阈值换取更可靠的模式排序。
4. 下轮可围绕三角主孔连续扫描 `0.24a–0.30a` 孔距、主孔圆角和两个副孔面积差，目标是把模式
   间隔从 `1.46 cm^-1` 提高到至少数 `cm^-1`，同时维持中心峰。

## 4. 如何理解“最佳”

这些阈值是给定层栈、理想孔形、冷腔线性 CWT 和有限器件开放边界下的总模态损耗，不是已经包含
泵浦效率、热透镜、空间烧孔和载流子动态的实验电流阈值。流片前至少要：

- 加入三角尖角的圆角半径和尺寸/位置 Monte Carlo 公差；
- 用更大的有限网格复核模式间隔；
- 用 RCWA/FEM/FDTD 校验最终 2–3 个几何的辐射 Q 和远场；
- 接入载流子、热效应和空间烧孔模型，确认实际起振模不会切换。

当前建议是：三角 Bravais 晶格优先做 `triangle_sat_08`（稳健）和
`distance_+0.420`（最低阈值）双路线验证；方形 Bravais 晶格优先做
`triangle_main_a045`，把超低阈值三孔方案作为近简并对照组。

本页的三角器件半径为 `30 μm`，不能与 `300 μm` 方形器件直接比较绝对阈值和发散角。统一到同一
纵向层栈和 `300 μm` 外接尺寸后的新结果见
[300 μm 同尺寸方形—三角对比](equal_size_square_triangular_comparison_zh.md)。
