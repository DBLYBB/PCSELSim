本文对应 `scripts/archive/legacy_20261008/design_triangular_three_hole_pcsel.py`。这里的“三晶格”指一个三角
Bravais 原胞内放三个空气孔：主孔位于原点，两个副孔分别位于 `+d1*a1` 与 `+d2*a2`。
它不是把三孔示意图送进旧的方形四波模型；每个候选都会重新计算介电常数 Fourier 系数、
纵向 TE0 模、Liang 六波 `Cb+Cr+Ch`、有限器件本征态与复矢量远场。

## 1. 为什么这样设计

单圆孔三角晶格保留较高对称性，最低阈值态可能在法线方向发生复振幅相消，形成中心奇点或环形
远场。给两个原胞轴各增加一个副孔后，孔的位置相位

```text
exp[2*pi*i*(m*u+n*v)]
```

会同时改变多组 Fourier 耦合系数。两个副孔等距、等面积时仍保留一定的平衡性；再用沿 `a1`、
`a2` 的径向椭圆提供适度各向异性，可解除不希望的模式简并，同时避免单轴扰动造成明显偏转。

脚本没有把高斯光斑乘到结果上。对每个有限本征模，程序先由六波辐射通道得到晶面复场
`Ex_rad(x,y), Ey_rad(x,y)`，再在实际六角网格坐标上直接计算 Fourier 远场。

## 2. 扫描了什么

本轮共实算 15 种三孔候选，拓扑始终不变，扫描内容包括：

- 副孔中心距离 `0.26a` 到 `0.36a`；
- 副孔等效圆半径 `0.07a` 到 `0.09a`；
- 圆形、径向椭圆、切向椭圆、同向椭圆和反向旋转椭圆；
- 两轴等距与故意错位；
- 总填充率 `0.13`、`0.15` 和 `0.17`；
- 主孔为圆形或轻微椭圆。

粗筛使用 `D=4`、纵向步长 `6 nm`、有限网格 `N=5`。评分对象始终是实际最低阈值模，不是从
六个分支中事后挑一张最好看的图。评分同时考虑：

1. 法线中心强度与全图峰值之比；
2. 峰值和能量质心偏离法线的角度；
3. 远场二阶矩椭圆率；
4. `1 deg` 圆锥内的功率比例；
5. 全 RMS 发散角；
6. 最近模式及中心暗模式的阈值间隔。

完整候选数据在
`results/custom_semiconductor_triangular_three_hole_optimized/01_screening.csv`，不要只看综合分数。

## 3. 当前获胜结构

高精度复算采用 `D=10`、纵向步长 `3 nm`，并对 `N=(7,9,11)` 的有限网格本征值作
`1/N -> 0` 线性外推。获胜候选为 `radial_main_y_d032`：

| 孔 | 原胞分数坐标 `(u,v)` | 椭圆半轴 `(rx,ry)` | 方向 |
|---|---:|---:|---:|
| 主孔 | `(0,0)` | `(0.18120a, 0.15756a)` | `90 deg` |
| `a1` 副孔 | `(0.32,0)` | `(0.09466a, 0.06761a)` | `-30 deg`，沿 `a1` |
| `a2` 副孔 | `(0,0.32)` | `(0.09466a, 0.06761a)` | `+30 deg`，沿 `a2` |

总填充率为 `0.1500`。当 `a=341 nm` 时，主孔半轴约为 `(61.8,53.7) nm`，副孔半轴约为
`(32.3,23.1) nm`，两个副孔中心到主孔中心的距离均为 `109.1 nm`。

| 高精度指标 | 结果 |
|---|---:|
| 实际最低阈值模式 | A |
| 阈值 | `57.06 cm^-1` |
| `alpha L` | `0.1712` |
| 最近模式阈值间隔 | `21.88 cm^-1` |
| 远场中心/峰值 | `1.000` |
| 峰值偏离法线 | `0.000 deg` |
| 能量质心偏离法线 | `0.010 deg` |
| 二阶矩椭圆率 | `1.038` |
| `1 deg` 内功率 | `77.2%` |
| 全 RMS 发散角 | `2.04 deg` |

六个所跟踪分支中没有 `center/peak < 0.20` 的中心暗竞争模。最低阈值 A 模是居中的近圆单瓣；
图中的弱六重外围结构来自有限圆孔径和六个辐射通道，不应误称为理想无旁瓣高斯光束。

## 4. 本轮得到的设计经验

### 4.1 等距比错位更重要

故意令 `d1=0.28a, d2=0.34a` 时，粗筛最低模的峰值偏移约 `0.67 deg`，中心/峰值降到约
`0.55`。两个轴上的传播相位不平衡会产生波束偏转和椭圆化。若目标是法线单瓣，应先保持
`d1=d2` 和两个副孔等面积，再用较小的椭圆率微调。

### 4.2 孔间距不是越近越好

圆副孔从 `0.26a` 移到 `0.30a` 时，模式排序与相消关系会突变；本轮 `d=0.30a, rs=0.07a`
甚至重新得到近暗心最低模。位置决定 Fourier 系数的复相位，因此不能只按总填充率推断远场。
本轮较稳定的亮心区在 `d=0.32a` 到 `0.36a`，但这个区间只适用于当前层栈和波长。

### 4.3 对称的径向椭圆有利于兼顾解除简并与光束平衡

两个副孔的长轴分别沿 `a1` 和 `a2`，比把两个椭圆都朝同一个笛卡尔方向更容易保持法线峰值。
同向椭圆候选虽有很高中心像素，粗筛峰值仍偏移约 `0.75 deg`；中心/峰值单个数字不足以判断
光束质量。

### 4.4 主孔只需弱各向异性

主孔椭圆率约 `1.15` 时，本轮 `1 deg` 内能量从若干圆主孔候选的约 `0.55–0.69` 提高到粗筛
约 `0.80`，同时没有造成可见波束偏转。过强的主孔各向异性可能重新拉开偏振分支并增加椭圆率，
应做连续扫描而不是继续单调增大。

### 4.5 优化必须针对“实际会先起振的模”

某个高阶分支有漂亮光斑并不代表器件会输出它。必须先按有限器件阈值排序，再评价最低阈值模；
同时要求竞争模具有足够阈值间隔。本轮最近竞争模高 `21.88 cm^-1`，但加入载流子空间烧孔、温升
和制造误差后间隔可能变化。

### 4.6 一个指标不能代表好光束

至少同时查看中心/峰值、峰值偏移、质心偏移、椭圆率、包围能量、发散角和二维图。中心像素接近
1 的光斑仍可能偏轴、双瓣或有强旁瓣；RMS 发散角也会被很弱但很远的旁瓣放大。

## 6. 可信度边界与下一步

当前结论属于六波 3D-CWT 降阶模型内的设计筛选，不是流片保证：

1. 有限器件采用一阶六角特征网格，报告阈值来自三网格线性外推；还应增加 `N=13,15`。
2. 需要对三个孔的半轴、位置和角度做制造公差 Monte Carlo 扫描。
3. 需要用 RCWA/FEM/FDTD 复核无限周期复频率、偏振、旁瓣和辐射 Q。
4. 应加入电流扩展、增益竞争、空间烧孔、热透镜和折射率温漂后再预测实际起振模式。
5. 如果扩大器件，主瓣会变窄，远场采样范围和分辨率也必须同步收敛。

因此，当前结构可以作为下一轮连续参数优化和全波验证的起点，不应直接当作最终掩膜版图。
