## 直接运行

在 PyCharm 中右键 `scripts/archive/legacy_20261008/run_custom_wang2024_triple_lattice.py`，选择 **Run**。命令行等价命令：

```powershell
python scripts\archive\legacy_20261008\run_custom_wang2024_triple_lattice.py
```

结果只写入 `results/custom_semiconductor_wang2024_triple_lattice`，不会覆盖
`results/custom_semiconductor_inoue2019`。脚本顶部 `STEPS` 控制每一组输出；默认运行 01–07，
关闭 08 时域。若只想重画晶格和模式，可运行：

```powershell
python scripts\archive\legacy_20261008\run_custom_wang2024_triple_lattice.py --only 02_lattice 05_linear_modes 06_mode_atlas
```

## 哪些参数直接来自论文主文

Wang 等 2024 主文给出的 structure 1 参数已经逐项写入入口：

- 方形晶格常数 `a=474 nm`；
- 每个晶胞三个直径 `90 nm` 的圆孔，孔内为 InP；
- 三个孔心为 `(-a/4,-a/4)`、`(a/4,-a/4)`、`(a/4,a/4)`；
- PC 厚度 `430 nm`，PC 区边长 `300 um`；
- p-mesa 直径 `220 um`，接触窗口直径 `200 um`，n 电极内径 `240 um`；
- PC 与 MQW 限制因子分别约 `52%` 与 `6%`；
- 发射波长约 `1551 nm`，CW 阈值 `0.52 A`，阈值电流密度 `1.66 kA/cm^2`；
- structure 1 最低阈值模式损耗约 `28 cm^-1`，最大 180 度耦合约 `253 cm^-1`；
- 实验远场 1/e² 全宽约为 x 方向 `3°`、y 方向 `17°`。

论文式 (4) 的结构因子在这三个孔心处满足 `|A20|=3`。程序直接从三个圆孔计算介电常数 Fourier
系数，而不是把 3 人工乘到耦合矩阵上。

## 本次实际计算得到什么

最终结果的机器可读汇总位于 `00_wang2024_comparison.json`。本次运行得到：

| 量 | 论文主文 | 当前计算 | 判断 |
|---|---:|---:|---|
| 填充率 | 约 8.5% | 8.495% | 一致，来自几何 |
| Bragg 波长 | 约 1551 nm | 1550.858 nm | 很接近；纵向等效层栈以公开约束校准 |
| PC 限制因子 | 52% | 50.892% | 接近 |
| MQW 限制因子 | 6% | 标量 TE0 为 5.376%；时域采用论文 6% | 接近 |
| 180 度总耦合幅值 | 最大约 253 cm^-1 | 297.31 cm^-1 | 高约 17.5%，仍是同一量级 |
| 最低模式幅度损耗 | 约 28 cm^-1 | 4.624 cm^-1；`2 alpha=9.249 cm^-1` | 不符合定量值 |
| 阈值电流密度 | 1.66 kA/cm² | 1.655 kA/cm² | 圆形 200 um 窗口与 0.52 A 的几何换算一致 |
| 冷腔反推阈值 | 实验 0.52 A | 占位载流子参数给出 0.295 A | 不可作为预测 |

因此，这次结果证明三孔 Fourier 结构因子、填充率、Bragg 条件和纵向场约束已经正确接入原来的
几何驱动 3D-CWT，但**尚不能宣称完整复现 Wang 的 28 cm^-1 模式损耗**。不要通过手改模式损耗或
乘一个经验常数来伪装吻合；下一步应取得 Supplementary Table S1，加入真实外延、折射率色散、
掺杂自由载流子吸收、上下边界/电极反射以及论文实现采用的 Green 函数边界。

## 怎样读模式图

`06_mode_atlas.png` 中 A 与 B 的最低损耗只相差约 `0.0045 cm^-1`，在当前网格和等效层栈下几乎
简并。A 包络出现水平节点，B 包络是中心峰；论文 Fig. 6(e) 插图更接近中心峰。不能只凭程序按
极小数值差排序后写出的“A 最低”就断言模式形状已经复现，必须先完成网格、外延和边界模型验证。

当前理想开边界单模远场约在 1 度量级，并且具有晶格对称结构；它不应等同于论文实验的
`3° x 17°` 椭圆远场。论文把实验椭圆归因于多模、非均匀近场以及解理面反馈，而这些机制当前
预设没有建模。

## 为什么默认不跑第 08 步

入口虽然复用同一套 Inoue 时域四波方程，但 1550 nm InAlGaAs 的增益曲线、透明载流子密度、
复合系数、热效应和电流扩展参数不能从 950 nm InGaAs 预设照搬。脚本保留了一组明确标为占位的
参数，方便日后接入数据；在获得独立材料参数之前，`08_time_domain=False` 是有意的物理审慎选择。
论文实验在 0.60 A 已出现多模，而当前时域只投影并跟踪一个选定带边模，也不能复现该多模光谱。

## 上一轮 Inoue 输出复核

`results/custom_semiconductor_inoue2019` 的结果在代码内部是自洽的：A 模最低，`alpha L=0.22865`，
与 Liang 的有限区域量级相符；冷腔反推阈值 `0.603 A` 与采用的论文阈值 `0.7 A` 接近；晶胞和
远场由同一几何耦合矩阵生成。它仍只是部分定量复现：

- Bragg/光谱中心约 `949.15 nm`，低于 Inoue 图中的约 `950.6 nm`；
- 2.8 倍阈值的光子近场明显偏向左侧，没有形成论文中更均匀的主体分布；
- 4.2 倍阈值仍主要是单峰，而论文展示约 26 pm 的双峰结构；
- 高电流弛豫振荡频率偏高；
- 双椭圆尺寸是公开中心位移基础上的理想化，原始 SEM 三维轮廓和作者复耦合矩阵没有公开。

所以可以把上一轮用于“方程链路和趋势验证”，不能称为逐点完全复现。原输出没有被本次 Wang
预设覆盖。
