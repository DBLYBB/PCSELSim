## 这套脚本解决什么问题

`scripts/archive/legacy_20261008/run_custom_ybyag_pcsel.py` 保留半导体平台的方形晶格四波光学骨架，但删除电流注入、电子—

- 器件尺寸、光学损耗、Yb 浓度、寿命和截面对结果的灵敏度分析。

它还不是完整的三维热—应力—泵浦传播—空间烧孔模型。

## 状态变量与方程

总 Yb 浓度为 `Nt`，上能级分数为 `f=N2/Nt`，基态为 `N1=Nt-N2`。1030 nm 的净材料增益为

```text
g(f) = sigma_e,l N2 - sigma_a,l N1
     = Nt[(sigma_e,l + sigma_a,l) f - sigma_a,l].
```

泵浦光子通量 `Phi_p=I_p/(h nu_p)`，泵浦吸收与受激发射速率分别为
`W_ap=sigma_a,p Phi_p`、`W_ep=sigma_e,p Phi_p`。脚本中的共享反转方程是

```text
df/dt = W_ap(1-f) - W_ep f - f/tau
        - Gamma vg g(f) sum(S_m)/Nt.
```

第 `m` 个 PCSEL 模式的光子密度满足

```text
dS_m/dt = vg[Gamma g(f) - alpha_m] S_m
          + beta_sp Nt f/(tau M).
```

其中 `alpha_m` 包含内损耗、面辐射损耗和边缘损耗，`M` 是参与计算的模式数。由净增益等于损耗可得

这里统一定义 `S_m=N_photon,m/V_gain`。因此反转消耗和光子增加的受激项都必须乘相同的
`Gamma`，确保少一个激发离子对应多一个光子。2026-10-08前版本缺少反转消耗项的 `Gamma`，
稳态功率可能偏小一个限制因子；现在增加了数量/能量守恒测试和 `ybyag_energy_budget`。

```text
f_th,m = [alpha_m/(Gamma Nt) + sigma_a,l]
         / (sigma_e,l + sigma_a,l).
```

当 `f_th>1` 时，该模式在当前截面和损耗下不可达到，图中会明确标为 `unreachable`。

`f_th<1`也不足以判断起振。有泵浦受激发射时无限强度反转上限是
`f_inf=sigma_ap/(sigma_ap+sigma_ep)`，默认只有 `0.875`；当前局域强度下的上限为
`f_0=W_ap/(W_ap+W_ep+1/tau)`。新程序同时输出所需局域阈值强度和默认泵浦可达性。
`alpha_m`在光子方程中是功率损耗；从有限本征值场损耗转换时使用 `2*alpha_field+alpha_internal,power`。

输出功率采用所指定的面辐射/输出损耗：

```text
P_out,m = h nu_l vg alpha_out,m S_m V.
```

## 为什么没有沿用半导体的纳秒时间步

Yb:YAG 上能级寿命约为毫秒，而 PCSEL 光场传播时间在皮秒量级。若把二者用同一个显式二维 CFL
时间步直接推进，计算量会跨越约九个数量级。当前版本因此用刚性 BDF 积分器求解“一个共享反转仓 +
四个模式光子密度”的平均场速率方程。这个分层方法可以显示其近似范围内的阈值和模式竞争，但不能给出横向泵浦
不均匀导致的空间烧孔；后续应把 `f` 扩展为 `f(x,y,t)` 并加入泵浦传播。

## 默认参数与来源

默认值是可运行的室温示例，不是某块晶体的证书数据：泵浦 940 nm、激光 1030 nm、折射率约 1.82、
上能级寿命 0.95 ms、约 1 at.% 的等效 Yb 浓度。Yb:YAG 必须考虑激光波长处的基态再吸收，不能按
理想四能级介质处理。准三能级建模框架可参考
[Taira、Tulloch 与 Byer 的连续波 Yb:YAG 模型](https://doi.org/10.1364/AO.36.001867)。
温度会显著改变 940/969 nm 泵浦和 1030 nm 激光截面；跨温度建模时应替换为相同温度、掺杂和偏振
条件下的数据，可对照
[温度相关 Yb:YAG 光谱参数研究](https://doi.org/10.1364/OME.505813)。默认的 1030 nm
吸收截面量级还可与
[Yb:YAG 放大器模型与实验参数](https://www.lmaleidykla.lt/ojs/index.php/physics/article/download/4641/3860?inline=1)
交叉检查。
0.95 ms寿命以及20–200 °C吸收/发射截面的实验对照还可见
[Yb:YAG、Yb:LuAG和Yb:CaF2温度光谱测量](https://opg.optica.org/josab/abstract.cfm?uri=josab-29-9-2493)。

对真实样品，应优先使用供应商或自行测量的吸收/发射截面、荧光寿命和实际 Yb 离子密度。不要只改
“掺杂百分比”而不重新换算 `YB_DOPANT_DENSITY_CM3`。

## 法向、单端和双端边入泵浦的39组初筛

新 `evaluate_ybyag_pump_architectures.py` 用一维起振前饱和传播比较 1/5/10 倍默认掺杂、
4/15/100 μm厚度、0.5/5 mm横向尺度和两种方向，共36组；再补3组相同总入射功率的双向边入。
它求解 `dI/dz=-Nt[sigma_ap(1-f_0(I))-sigma_ep*f_0(I)]I`，不是均匀反转下的普通指数吸收。
同一个500×500×4 μm³体积、同局域25 kW/cm²，法向入射62.5 W仅吸收0.01272 W；
理想边入0.5 W可吸收0.01263 W。入射功率差125倍是入射截面积与吸收路径的差别，不代表
真实耦合效率能达到100%，也不代表已有可起振PCSEL。4 μm高度难以导入真实泵束，厚/双包层
波导有实验依据，但必须重新求信号与PC重叠。长路径改善利用率也导致反转非均匀。

5 mm路径、4 μm厚、总5 W理想边入条件下，5倍默认掺杂的最低局域材料增益从单端0.968提高到
双端2.716 cm^-1；10倍从单端-1.301提高到双端1.111 cm^-1。高掺杂虽然吸收大，单端末段可能
再吸收。该初筛支持先优化双向/分段泵浦和反转均匀性；不构成新浓度光学层栈或实际起振验证。

## 国内外制造文献应如何使用

国外 [15 μm PLD Yb:YAG普通波导激光](https://doi.org/10.1364/OME.6.000091) 与国内
[100 μm陶瓷YAG/Yb:YAG/YAG平面波导](https://doi.org/10.1038/srep31289)、
[2024喷墨打印陶瓷波导](https://doi.org/10.1002/adpr.202300320) 支持实际平面波导路线。
它们的端面腔、厚度、掺杂、折射率和泵浦方式不等于当前4 μm表面PC假设。
`n_core=1.8220`是待测输入，不可把Yb:LuAG的实测折射率直接移给Yb:YAG。

[2019晶体纳米孔](https://doi.org/10.1038/s41566-018-0327-9)、
[2025 WEALTH纳米孔](https://doi.org/10.1038/s41467-025-62426-1)、
[2026种子辅助YAG近圆孔](https://doi.org/10.37188/lam.2026.038) 证明晶体内部圆/椭圆孔制造
有研究依据；三角尖角孔需要另外验证。纳米孔能做出来不代表其辐射、散射和热损耗已经适于激光。
[2016 PCSEL泵浦Yb:YAG](https://doi.org/10.1364/OL.41.004653) 是半导体PCSEL做泵源，
[2026国内全固态SSH激光](https://doi.org/10.1038/s41467-025-68173-7) 是Nd:BaLaGa3O7
微米波导阵列加两镜端面腔，均不能作为Yb:YAG四波/六波自身PCSEL验证。

## 与半导体模型相同和不同的部分

相同：晶格/倒空间描述、A/B/C/D 基底、4×4 复耦合矩阵、有限器件开放边界、单晶胞 Bloch 重建、
有限孔径远场处理。

不同：半导体使用电流注入的二维载流子方程与 Inoue 时域光场 PDE；Yb:YAG 使用光泵浦准三能级
平均场 ODE，并显式包含基态再吸收。两者共享光学模式标签，不共享增益介质方程。

几何生成三维复耦合/辐射矩阵这一步已经完成为可运行原型。下一阶段要成为定量工具，至少还需：
由可制造的实物层栈替换当前假设，加入泵浦在晶体中的空间吸收、二维或三维反转、热透镜和热应力、截面随
温度变化、非辐射猝灭/上转换以及实验输出耦合标定。
