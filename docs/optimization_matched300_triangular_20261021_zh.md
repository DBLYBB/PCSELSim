# 300 μm 三角晶格 PCSEL：中央主孔与双方向副孔最终优化

本轮已测且通过正式验证的低阈值方案为**圆角三角主孔＋两个不等距离圆副孔**。最细正式结果采用 N91 / D48 / dz1 nm，实际周期 **320.837227751 nm**，最低模式独立闭频 **950.000229228 nm**，材料阈值增益 **72.688485 cm⁻¹**，远场轴比 **1.018360**，中心强度为峰值 **99.5792%**。这是本轮已搜索并验证的候选，不是全局最优或动态单模证明。最终入口为 results/current/matched300_20261021/triangular/final_summary.json。

## 统一比较条件

所有比较腔的名义外边界均为 **300×300 μm 方腔**。半导体保留共同 Inoue 表 I 完整层栈：PC190 nm、GaAs110 nm、spacer25 nm、三层10 nm InGaAs量子阱及三层20 nm势垒，相同包层，材料内部**强度**损耗5 cm⁻¹。未混入旧PC120 nm或400 μm结果。孔面积引起的PC平均折射率和真实TE0约束因子改变保留在物理模型中，没有固定Γ来人为降低阈值。

初筛按Bragg≈950 nm定周期；正式方案按有限腔实际模式重新设计周期，要求最低模式独立闭频950±0.05 nm。本方案主模式真实波长950.000229 nm，不能用初筛Bragg标签代替。阈值材料增益采用 (2α_field+5 cm⁻¹)/(Γ n_active/n_eff)。

远场使用实际复杂Jones场，在共同±1°角窗比较 |Ex|²+|Ey|²。圆度同时检查二阶矩轴比、中心亮度、径向残差与半高连通性，不只拟合一个圆形二阶矩。

## 扫描与实际横模检查

完成主要广域目录 **2212次参数尝试、568次通过几何后执行有限腔求解**，另99次N17 Pareto复筛。包括1024点18维Sobol＋45个锚点、567点fill/share/distance网格、256和192点局部搜索、128点N17/D32高阶适应性重新优化。随后按实际950 nm参考，在N65完成40次局部／角度尝试，36次通过严格分支跟踪；数值包含对照和重复基线，不冒充独立物理几何数量。

扫描了中央与两副孔circle/ellipse/rounded-triangle形貌、面积分配、两侧独立距离／方向、三个孔的朝向与椭圆长宽比。主孔固定原点，两副孔不可消失，主孔必须最大。早期违反主孔面积等级的探索记录已排除正式候选。

N65实际参考局修发现主孔旋转方向能同时改善阈值、圆度与网格稳定性。正式1.720752°对应相对初始33.720752°的−32°改变，是**本轮已测有效候选**。−40°未通过严格跟踪检查，−52°阈值回升，这些只属于边界探索，不能当作角度严格全局最小值证明。

最终谱验证没有用六个Γ家族间隔代替实际横模：
1. 在最终实际周期与参考λ下，完成N13/D48/dz1的**全部4926维有限离散谱**；非有限、原pencil残差和负α筛选均丢失0根。
2. 取最低40根复杂极点的实部与imag×1／×0.5、插值复杂场，共80个目标导引到N39，找到**156个独立有限极点**，保留完整标量谱。
3. 将N39最低12个实际场继续到同节点跨度的N91，**12／12**通过残差和重叠检查。
4. 以三对反向波独立连续传输根为额外目标，三方向×两种高perp初始场，在N91完成**6／6个复杂shift窗口**，找到24个独立条纹极点；其中最低g130.342819 cm⁻¹，高于主模式。
5. 两池合并得到36个独立场，最低六根分别重建TE0、C(λ)、辐射和有限腔，独立闭频后按真实材料阈值重新排序。

近实轴首个条纹目标曾长时间未返回有效窗口，已明确中止并保留run_status，改用独立连续传输的真实复杂根，没有放宽本征残差门槛。连续双波极限仅作搜索导引，不是二维阈值的严格下界。完整N13粗谱、局部宽谱N39、N91续算与显式挑战仍不等于穷尽N91全部离散谱或全部光学频段。

## 被推翻的旧方案与三角晶格研究价值

旧“大圆主孔＋近圆双副孔”曾在Γ／均匀实轴shift池中得到N39亮圆态g107.907873、轴比1.009和表观间隔13.82%。独立双波导引随后在真实二维有限腔找到更低的暗条纹态，独立闭频 **g61.494754／61.495260 cm⁻¹、λ946.975167 nm**，推翻其最低态资格。旧13.82%不能作为真实最低模式隔离。另有三圆孔在粗网格看似近圆、细网格明显变椭圆的反例；均已保留必要场和标量证据，没有混入最终推荐。

三角晶格具有三对传播／反馈方向与矢量偏振耦合，可通过两副孔位置和中央三角孔朝向联合调节反馈、辐射及模式损耗。本轮获选几何本身受控不对称，却在共同有限方腔中获得低阈值近圆光斑，说明有限边界补偿和矢量耦合调控比单纯追求六重几何对称更有研究价值。旧暗条纹反例也说明三角晶格不会自动保证最低模式明亮或隔离；研究应比较真实有限横模、出耦取舍和偏振纹理，而非仅比较Γ简并。

## 代码、证据与保存策略

入口为final_summary.json、configs/optimized_matched300_20261021/triangular_finalists.json和formal_low_gain_verified_N91。primary_array_keys列出main复场、C、直接本征值、辐射、Jones和坐标键。最终六根直接保存delta_per_m，不靠旧闭频残差重建；最小模式原pencil相对残差约6.1×10⁻¹⁴，实际频率残差约1.3×10⁻⁶ m⁻¹。readback_validation_final.json逐数组检查有限性，并从Jones独立重算圆度／偏振。

私有完整粗谱QR使用 H=K M⁻¹=C+iD M⁻¹，标准右本征向量直接是物理中心φ。N5／N7原QZ与QR的全部690／1482极点经一对一匹配和简并子空间复核，相对谱差≤9.21×10⁻¹⁴，最差场／子空间差2.31×10⁻⁸，并保留原pencil残差和能量预算。严格中心inverse continuation、精确可分离point-sum远场、精确C(λ)残差门控Newton也分别对原流程验证，未更换物理方程或降低门槛。
