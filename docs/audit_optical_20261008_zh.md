## 2. 新发现与已实施修复

### 2.1 P1：阈值外推不能继续隐藏失败

位置：`triangular_finite.py::solve_triangular_finite_modes_converged()`、`custom_analysis.py::solve_finite_modes_converged()`。

原实现对三个网格作1/N直线拟合，并把任何负损耗截距夹到零。该策略会把离散/分支拟合失败表现为“无损腔”。本轮改为：

1. 强制网格严格递增，拒绝重复网格。
2. 保存原始截距、经验敏感度、最细网格损耗。
3. 超出舍入误差的负截距拒绝采用，返回最细被动网格值并发出警告。
4. 敏感度超过截距25%时标记`grid_sensitive`并警告；其他拟合仅标记`provisional`，不称已收敛。
5. 场形仍使用最细实际本征矢，`grid_alpha_per_m`保留它对应的真实网格本征值。外推后的损耗与场不再被描述成同一个已求解本征对。

修复入口：`numerical_quality.py:13`；四波入口约`custom_analysis.py:377`，六波入口约`triangular_finite.py:328`。新增字段为向后兼容的附加字段；旧脚本仍可运行，但下游阈值/Q/优化表必须同步展示状态。

### 2.2 P1：六波Far-field正号导致角度和相位镜像

Liang式(4.24)使用`exp[-i(kx*x+ky*y)]`。原六波函数使用正指数，而四波FFT使用负指数。对中心对称亮斑强度图，这个问题很难察觉；对定向结构、倾斜出射和复相位，会交换观察方向。

已在`triangular_finite.py::triangular_vector_far_field()`改为负指数。新增回归使用已知`+0.4°`相位梯度孔径，要求远场峰值仍为`+0.4°`，避免只测“中心亮斑”而遗漏符号错误。

### 2.3 P1：有限视窗能量不等于全部出射能量

两个光学模块均以评估视窗中的强度和为分母：

```text
E0.5_window = sum(I where angular radius <= 0.5 deg) / sum(I in evaluated window)
```

因此此前“0.5°内包含总能量99.57%”应改为“在评估的±1.5°方形视窗内，0.5°圆内的强度积分比例约99.57%”。这不证明整个半空间有99.57%的输出被集中，也没有包含所有真实角度的重建误差。角度积分忽略了大角度的严格立体角Jacobian，仅适用于此次小角度对比。

字段`full_rms_divergence_deg`为兼容保留，但其实际定义是相对于法线的`2*sqrt(<theta_x²+theta_y²>)`。它不是FWHM、1/e²直径、ISO D4σx/y或M²。新元数据记录`surface_normal_radial_second_moment`及`evaluated_angular_window`。

### 2.4 P1：六波点采样会在大角度产生虚假复制瓣

直接对粗特征节点求和，相当于对该特征晶格上的采样孔径变换。取点数增加、绘图更加平滑不会消除采样复制谱。

若`h=R/N`，轴坐标物理点为`(h(j+k)/2, sqrt(3)h(k-j)/2)`，第一采样BZ满足：

```text
|kx +/- ky/sqrt(3)| <= 4*pi/(3*h)
|ky| <= 2*pi/(sqrt(3)*h)
```

方形角度视窗四个角均无混叠的上限为

```text
theta_square_max = atan[2*lambda / (3*h*(1+1/sqrt(3)))]
```

本轮自动将视窗限制为该上限的98%，超范围时警告，并输出请求视窗、实际视窗、无混叠上限。历史300μm推荐的Bragg波长935.3925nm下：N=7/9/11/13的安全方形半视窗分别约1.057°/1.359°/1.661°/1.962°。N=11画±3°有混叠风险；N=11画±1.5°未超过这个方形上限，但仍只有粗节点近似的窗内积分。

真正改善远场精度要细化本征场和边界积分。可进一步采用具有明确物理孔径的分片线性场积分/单元面积权重并检查远场随网格和积分视窗的收敛；单纯插值或补零不会增加本征场物理分辨率。

### 2.5 P1：不能从本征值简并直接断言C4对称

原四波程序仅凭C/D带边本征值接近，就把C旋转90°当作D。物理E矢量旋转时`Ey -> -Ex`，原程序遗漏两个符号；同时`origin='lower'`的数组空间主动逆时针旋转对应`np.rot90(k=-1)`。已修复这两点。

此外，只有旋转后的场对实际有限算子的相对残差小于`1e-6`、且与原场非重复，才接受它为简并伙伴。否则保留直接求解的D模式并警告。新增测试证明具有C4对称的四波矩阵与该物理旋转算子对易。

### 2.6 P1：有限盒本征态不一定是导模

原纵向模块始终返回有限盒最高beta态。均匀介质或无有效芯层的结构仍会得到一个数值本征矢，不能据此证明PCSEL有导模。已要求`beta > k0*max(n_top,n_bottom)`，无束缚TE0时明确拒绝。

该条件只是必要的导模筛选；接近光线、弱束缚或多模情况下仍需padding收敛、TE1/TM模检查和外部波导模型。

## 4. 尚未完成的验证及其优先级

1. **P1：替代离散的交叉验证。** 按Liang(4.21)原staggered以及(5.18)广义质量矩阵实现独立求解，先复现圆孔CC与三角晶格单圆孔表格；不能仅用拟合增加小数位。
2. **P1：优胜候选的全波验证。** 至少一个独立RCWA/FEM/FDTD求解器检查无限周期带边频率、辐射Q、偏振及目标层栈反射影响。现有pytest不是全波验证。
3. **P1：半导体增益闭合。** 模态波长需落在真实材料增益谱内，载流子增益系数需随波长/温度标定，不能把原Inoue增益常数无条件用于所有新结构。
4. **P2：制造鲁棒性。** 几何最小周期间距、最小孔宽、深宽比、圆角、刻蚀偏置/侧壁倾斜以及位置和旋转误差需要硬约束与容差统计。39nm间距不是经过工厂确认的可加工承诺。
5. **P2：高阶与纵向收敛。** 对三角孔/圆角孔增加D和弧线采样数；对材料迁移增加dz和padding扫描。PSD只能限制被动性，不能证明相位/损耗精确。
6. **P2：远场与模竞争。** 报告窗内能量、评估窗、网格、FWHM/径向二阶矩的明确口径；更宽视窗需更细场及真实积分。当前只提取每个Gamma带边附近平滑基模，还未穷尽所有横向高阶模式。
7. **P2：色散和能带标签。** `delta -> a/lambda`当前使用冻结neff；严格的频率微扰应使用群折射率及材料色散。三角晶格中右端`X`为用户显示名，Liang使用J，通常三角BZ用K；图仅为两条方向上的近Gamma小段，不能理解为已算完整高对称路径。
