# Yb:YAG 全固态光子晶体激光模型说明

> **当前可信度边界：** 这个脚本的 Yb:YAG 准三能级速率方程可用于概念和量级检查，但它的光学
> `C` 仍是手填示例值，不能作为真实全固态器件的定量设计结果。普通厚块 Yb:YAG 加表面孔阵列并不
> 自动满足 PCSEL 四波模型；必须先给出支持目标 TE 导模的薄膜/复合波导，使
> `lambda=a*neff` 成立，再接入几何驱动 3D-CWT 后端。半导体脚本已经完成该后端，Yb:YAG 入口尚未
> 完成这一物理结构迁移。

## 这套脚本解决什么问题

`scripts/run_custom_ybyag_pcsel.py` 保留半导体平台的方形晶格四波光学骨架，但删除电流注入、电子—
空穴载流子扩散和半导体增益关系，替换成泵浦驱动的 Yb:YAG 准三能级粒子数反转。它现在适合做：

- 四个带边模式的损耗、阈值反转和模式竞争初筛；
- 940 nm 泵浦、1030 nm 激光下的反转建立与弛豫振荡；
- 泵浦—输出曲线、阈值泵浦强度和反转钳位；
- 器件尺寸、光学损耗、Yb 浓度、寿命和截面对结果的灵敏度分析。

它还不是完整的三维热—应力—泵浦传播—空间烧孔模型。

## 状态变量与方程

总 Yb 浓度为 `Nt`，上能级分数为 `f=N2/Nt`，基态为 `N1=Nt-N2`。1030 nm 的净材料增益为

```text
g(f) = sigma_e,l N2 - sigma_a,l N1
     = Nt[(sigma_e,l + sigma_a,l) f - sigma_a,l].
```

泵浦光子通量 `Phi_p=I_p/(h nu_p)`，泵浦吸收与受激发射速率分别为
`W_ap=sigma_a,p Phi_p`、`W_ep=sigma_e,p Phi_p`。脚本中的共享反转方程是

```text
df/dt = W_ap(1-f) - W_ep f - f/tau
        - vg g(f) sum(S_m)/Nt.
```

第 `m` 个 PCSEL 模式的光子密度满足

```text
dS_m/dt = vg[Gamma g(f) - alpha_m] S_m
          + beta_sp Nt f/(tau M).
```

其中 `alpha_m` 包含内损耗、面辐射损耗和边缘损耗，`M` 是参与计算的模式数。由净增益等于损耗可得

```text
f_th,m = [alpha_m/(Gamma Nt) + sigma_a,l]
         / (sigma_e,l + sigma_a,l).
```

当 `f_th>1` 时，该模式在当前截面和损耗下不可达到，图中会明确标为 `unreachable`。

输出功率采用所指定的面辐射/输出损耗：

```text
P_out,m = h nu_l vg alpha_out,m S_m V.
```

## 为什么没有沿用半导体的纳秒时间步

Yb:YAG 上能级寿命约为毫秒，而 PCSEL 光场传播时间在皮秒量级。若把二者用同一个显式二维 CFL
时间步直接推进，计算量会跨越约九个数量级。当前版本因此用刚性 BDF 积分器求解“一个共享反转仓 +
四个模式光子密度”的平均场速率方程。这个分层方法可以可靠显示阈值和模式竞争，但不能给出横向泵浦
不均匀导致的空间烧孔；后续应把 `f` 扩展为 `f(x,y,t)` 并加入泵浦传播。

## 默认参数与来源

默认值是可运行的室温示例，不是某块晶体的证书数据：泵浦 940 nm、激光 1030 nm、折射率约 1.82、
上能级寿命 0.95 ms、约 1 at.% 的等效 Yb 浓度。Yb:YAG 必须考虑激光波长处的基态再吸收，不能按
理想四能级介质处理。准三能级建模框架可参考
[Fan 与 Byer 的连续波 Yb:YAG 模型](https://opg.optica.org/ao/abstract.cfm?uri=ao-36-9-1867)。
温度会显著改变 940/969 nm 泵浦和 1030 nm 激光截面；跨温度建模时应替换为相同温度、掺杂和偏振
条件下的数据，可对照
[温度相关 Yb:YAG 光谱参数研究](https://doi.org/10.1364/OME.505813)。默认的 1030 nm
吸收截面量级还可与
[Yb:YAG 放大器模型与实验参数](https://www.lmaleidykla.lt/ojs/index.php/physics/article/download/4641/3860?inline=1)
交叉检查。

对真实样品，应优先使用供应商或自行测量的吸收/发射截面、荧光寿命和实际 Yb 离子密度。不要只改
“掺杂百分比”而不重新换算 `YB_DOPANT_DENSITY_CM3`。

## 输出步骤

01–07 与半导体脚本相同；08–10 是 Yb:YAG 专有计算：

- `08_ybyag_gain.png`：净材料增益、再吸收和各模式阈值反转。
- `09_rate_dynamics.png/.npz`：反转、四模式光子密度和输出功率随时间变化。
- `10_pump_scan.png`：最低阈值模式的泵浦—输出曲线和反转钳位。

默认泵浦强度设置在 A 模式阈值之上，因此第 09 步能看见起振和弛豫振荡。修改损耗或截面后，阈值会
移动；若不再起振，应先查看第 08 和第 10 步，而不是直接认定积分器出错。

## 与半导体模型相同和不同的部分

相同：晶格/倒空间描述、A/B/C/D 基底、4×4 复耦合矩阵、有限器件开放边界、单晶胞 Bloch 重建、
有限孔径远场处理。

不同：半导体使用电流注入的二维载流子方程与 Inoue 时域光场 PDE；Yb:YAG 使用光泵浦准三能级
平均场 ODE，并显式包含基态再吸收。两者共享光学模式标签，不共享增益介质方程。

下一阶段要成为定量全固态设计工具，至少还需：先确定可导模的 Yb:YAG 薄膜层结构并由几何生成
三维复耦合/辐射矩阵，再加入泵浦在晶体中的空间吸收、二维或三维反转、热透镜和热应力、截面随
温度变化、非辐射猝灭/上转换以及实验输出耦合标定。
