# 300 μm同尺寸中央主孔+对角副孔正方晶格优化

本报告的腔边长固定300 μm，与文献有限腔L一致；所有正式候选使用同一Inoue完整层栈和5 cm⁻¹内强度损耗。先用950 nm冻结参考做多参数筛选，再把实际最低被动极点的周期调到950 nm，冻结该周期逐根闭合竞争横模。不同尺寸或916 nm旧候选不参加本轮优劣排序。

推荐best_isolation：g₁=72.95378 cm⁻¹、已查材料增益间隔16.858%、η_rad=0.1984。较低g的两个Pareto方案保留较小隔离，不用它们的四族名义大间隔宣称强单模。

best_balanced 的轴比更接近 1；best_low_threshold 的径向 L2 反而更低。两种圆度度量分别保留，不把二阶矩轴比优先误写为所有径向轮廓都更圆。

主方案为中央圆孔（半径50.663712 nm）+圆角三角副孔，主/副面积各占总孔面积50%，总填充0.19894234；副孔面积形心(104.192759, 92.525629) nm，长宽拉伸比1.54597277、旋转-42.26134728°，周期284.723507434 nm。圆孔的旋转角和长宽比标签不参与物理形状；所有真实边界均另存actual_geometry_nm.json。

该共同300 μm面积的近似阈值电流为0.455515 A；材料增益间隔16.858%对应近似阈值电流间隔仅0.886%，因为透明载流子基线占主要电流。二者不可混用，也不代表上述电流倍数范围内已经证明动态单模。η_rad的分母包含被动横向漏光、局部辐射和5 cm⁻¹内强度损耗，不是±1°窗口功率占比或实验斜率效率。

圆度指标来自实际矢量远场总强度 |Ex|²+|Ey|² 在±1°窗口内的二阶矩；径向L2同时检查四瓣/六瓣等非椭圆畸变。圆形强度光斑不表示圆偏振。所有图均为英文标注，近场和远场均保留实际计算复场。

## 几何扫描与排错

320个LHS可制造几何、288个第一轮局部QZ、72个四分之一周期anchor、192个隔离方向局部QZ及192个actual-950局部QZ，共1064次几何评估。扫描总填充、主/副面积占比、副孔径向距离和偏角、两孔独立长宽比和旋转角、circle/ellipse/superellipse/rounded-triangle孔形。主孔面积形心固定在(0,0)，副孔沿对角线附近独立变位；不通过改腔尺寸或垂直层栈降低阈值。

四个Γ连接族各选一个状态会漏掉更低横模，不能使用该名义四族间隔宣称模式选择。N9/N11初筛及N17完整广义QZ核验保留全部残差合格有限极点；候选随后在N35/N49用带边±π/L、±2π/L及实轴移位搜索，补入完整粗谱的全部低阈值复极点作为移位目标；主方案N49新实际周期共140个目标，N65以最低12真实场插值延续验证最低模及近邻竞争，主方案和最圆方案分别闭合最低10根。低g支线的源rank9高横阶stripe未通过0.65场重叠门槛，记录为closure_failure；以之后独立seed补齐10个已验证根，不称原最低10根全部闭合。它的winner与nearest已验证，仍不作为强隔离主推。N65延续不是完整N65谱，跨网格高横阶stripe簇单一向量身份也不强称收敛。多例名义亮圆候选被更低非圆横模反超而否决，反例记录仍在紧凑JSON中。

早期筛选工艺有40 nm孔宽探索口径，正式候选全部以同一研究假设重查：最小周期孔隙40 nm、最小孔宽50 nm、边偏差3 nm、独立位置预算3 nm、曲率半径5 nm。该规则不是foundry认证。实际a调整后使用最终nm几何重新计算。
