# 有限腔、模式搜索与半导体动态的物理和算法审计

日期：2026-10-25。范围：有限四/六波离散、模式身份与筛选、频率闭合、近远场和偏振、Inoue 半导体速率方程与数值推进，以及这些步骤的输入输出和历史入口。Yb:YAG 速率与光学矩阵另见本轮其他审计，不在这里重复认证。

**本轮结论不是“所有代码完全按论文且物理严格”。** 现有正式路径有明确理论来源，并有可独立复算的离散能流、连续边值和频率残差检查；但是它仍是近 Bragg、慢包络、线性冷腔/近似速率模型。完整细网格谱、严格电磁全波、材料实验标定与热耦合没有因此获得证明。旧入口还保留了标定矩阵、人工辐射代理及上风截距等历史教学/对照路径。本轮明确修正了数处会静默隐藏非物理解或漏掉候选模式的算法风险。

## 3. 有限腔离散是否增加了虚假损耗

正式默认路径采用 Liang 的方向交错平均，而不是把所有场当作同一点上风未知量：

\[
M=(I+T)/2,\qquad D=(I-T)/h,
\qquad K=CM+iD,\qquad Ku=\mu Mu.
\]

保存和用于辐射、功率的是系数点场 `Φ=Mu`。原始场算符为 `K M⁻¹`，因此残差是在同一个物理离散方程上计算，不是只检查移位反演的内部残差。

方向质量矩阵不是 Hermitian 正定矩阵，不能直接将它塞入要求该条件的 `eigs(A,M=M)` 路径。代码显式求 `(K-σM)⁻¹M` 的特征值；小矩阵独立 QZ 求同一广义问题。稀疏与稠密两条路径均检查原方程残差。

离散恒等式

\[
M^\dagger D+D^\dagger M=(I-T^\dagger T)/h
\]

将输运耗散定位于出射边界，而不是上风体扩散。本轮在圆形、六边形和方形六方向掩模上，归一化恒等式残差为 0，边界通量算符非负。它不消除阶梯边界几何误差；相同名义孔径不等于离散节点跨距完全一样，必须分别细化。

独立连续 DFB 基准以常系数 ODE 的矩阵指数直接施加 `R(0)=0,S(1)=0`，不使用本有限差分算符构造参考解。连续根为 `3.3797188375 + 0.9846690538 i`；N=8/16/32/64 的绝对误差约为 0.03328、0.008289、0.002070、0.0005174，逐次缩小约 4 倍，符合交错中心近似的二阶收敛。该基准证明此类常系数边值问题的数值一致性，不是任意强反差 PCSEL 的全波认证。

历史 `legacy_upwind` 仍有数值体扩散，并保留 `1/N→0` 截距路线；截距可能与保存的最细本征场不构成同一本征对。它仅适合明确标记的历史方法对照，不可与正式 `staggered` 混合排名。正式交错网格路径保存实际最细网格本征值/场，拟合仅报告敏感度，不替换结果。

## 4. 模式搜索没有严格保证完整性

`custom_analysis.solve_finite_modes` 和 `triangular_finite.solve_triangular_finite_modes` 的职责是每个 Γ 族附近选一个平滑代表态；评分包含粗糙度、族投影、被动性等。这种评分用于**选择已求出的真实本征向量**，不是生成或修饰场，但它不能等同于最低阈值全横模搜索。

多复移位、粗谱 QZ、条纹种子与细网格延续是更广的挑战策略。粗网格完整谱不等于细网格完整谱；插值只供初值，最终仍重新解细网格算符。失败和未闭合的分支应留记录，不能从“完成77次尝试”推导为“77次均成功”。

非正规算符有三个需要分开的概念：

1. 数值上重复求得同一个复极点和同一场；应去重。
2. 真简并复极点的不同独立方向；应保留子空间维数。
3. 已分辨的不同复极点但场高度平行；应分别保留。

统一 `mode_identity` 检查第 1/2/3 项，本轮小基准均通过。该函数不能替代谱搜索，也不能自动辨认不同频率或不同算符的模式身份。对频变模型必须先核对实际频率、几何、纵模族和数值算符。

对称性产生的伙伴也不是凭 Γ 点简并自动制造：四波 C4 或六波旋转/反射生成的候选，只有在同一有限算符上通过独立残差、且扩展子空间时才被接纳。不满足时保留原本直接解出的状态。

## 5. 闭频、固定几何与分支延续

`frequency_cwt.py` 及正式闭频脚本要求

\[
F_j(\lambda)=\delta_{\rm bg}(\lambda)-\operatorname{Re}\mu_j[C(\lambda)]=0.
\]

每次试探波长重算纵向 TE 模、C 矩阵、有限场；周期和层厚在一次固定器件求解内不变。周期设计是独立的外层设计步骤，不能在每个竞争模闭频时分别调周期。

两种残差必须同时检查：原离散本征对残差和实际频率失谐残差。一个冻结矩阵可以有机器精度的本征对，却不满足物理频根。本轮有相应零本征残差/大频率残差反例。

波长预测器中的群折射率 Newton、割线、移位偏移，只用于寻找解；最终须在原 `C(λ)` 上复算验收。移位改变 `σ` 不改变器件矩阵。场重叠只能辅助追踪，在接近异常点、近共线分支或交叉处仍可能换支；因此失败拒绝及多种种子很重要，不能凭较高重叠宣称唯一分支已证明。

这里闭合的是近 Bragg 标量慢包络 CWT 的实频冷腔条件，不是全 Maxwell 复频极点，也不包含激射后增益牵引、热漂移和饱和场重整。光学审计另指出离 Bragg 时 `βref/β0` 与群速度/增益权重替换的近似，不能只改单个因子后仍声称全式精确。

## 6. 近场、远场、偏振及绘图

物理场链为：有限本征包络 → 几何推导的复辐射 `Ex,Ey` → 对真实 Cartesian 坐标作复数 Fourier 变换 → 同一尺度的两偏振强度相加。Liang (4.24) 中的 `tan θ` 和倾斜因子在对应函数中保留。它本身是论文的近轴标量辐射近似，不是任意大角度矢量远场。

三角网格没有被直接当作规则矩形像素 FFT。快速路径只把完全相同的物理坐标归并，分离指数求和；未舍入坐标或空间插值。本轮与逐点逐角手工复数求和比较，相对误差约 `4.2×10⁻16`。两 Jones 分量保留相对尺度和相位，不能独立峰值归一化后再谈偏振。

零填充只提高角度采样密度，不提高原场 Nyquist 上限、不缩小真实光斑。三角函数明确限制无混叠角窗；设计指标同时记录源采样和角窗。报告中的包围能量、二阶矩、Stokes 积分都是指定小角窗内的量，不是半球总能量、实验 M² 或时间退偏振。

`design_objectives` 的中心亮度、半高连通性、轴比、径向 L2 是工程目标，不是从某一论文直接得到的普适合格阈值。轴比近 1 并不能排除多瓣或圆环。`polarization` 的 S3 正负约定有明确记录，未附会左右旋命名。

`plotting.py` 直接读求解数组。显示窗口、峰值归一化、对数/色标和 Gouraud 绘制只影响显示；`io.save_result` 无损保存复数组。但 `radiation_proxy_field` 的 `x±iy` 等孔径因子是人为示意，不得用于物理设计认证；本轮为此添加显式警告。归档 Liang 脚本中的检查点拟合、`target_flatness` 与人为光斑同样仅属参考图，不是独立计算预测。

## 7. 半导体动态按论文实现到什么程度

已核对：

- 耦合按官方勘误为 `+i(c/ng) CΦ`，正 Im(C) 对应场振幅衰减。
- 场增益/损耗项是强度系数的一半；有限冷腔的 Im(μ) 是振幅损耗，材料阈值需 `2 Im(μ)+α_internal`，内损耗只加一次。
- Inoue (11) 的有理增益函数保持负增益。透明点以下吸收光子产生载流子，没有截掉负增益。
- 载流子单位在内核为 m⁻³，输入 cm⁻³ 仅转换一次；厚度、SI 电荷和泵电流单位相接。
- A10 的模增益为 `Γ(n_active/n_eff)g_active`；时间折射率项 `γ=2Γ/n_active (dn/dN)dN/dt` 是实振幅率，与相位失谐不同。
- 零边界只施加在入射特征线上，局域耦合子步也约束入射分量，避免禁入波在子步中被暂时激发再投影掉。
- Lax–Wendroff 内部传播与单边出射边界的精度不同；已有固定网格独立矩阵指数基准检查时间步收敛，不能据此省去空间收敛。
- 显式 Heun 的二维扩散条件另行检查 `D dt_sub/dx²≤1/4`。该条件不控制任意强受激耗尽，本轮新增逐阶段正性/有限性失败机制。

**并非完全逐式、精确能量闭合的部分：**

1. 自发辐射噪声是已标注的网格种子模型，未公开严格 Langevin 噪声相关和绝对线宽标定。通过期望光子注入量测试，只能支持该种子实现的一致性，不能支持实验线宽。
2. 注入误差函数平滑是经验电流扩展，不是电学漂移—扩散求解；N/τ 是论文简化复合模型，未自动包含任意材料的 ABC 复合和热反馈。
3. A10 的模增益与正文 (10) 的活性层光子密度/受激项，按现有写法照入同一求解器后，不能宣称严格的控制体积能量交换。取总场能量 `2ε0 n_eff n_g Σ|Φ|²`、载流子每次受激跃迁 `ℏω`，可独立得到

   \[
   \frac{P_{\rm field,gain}}{P_{\rm carrier,stim}}=\frac{n_{\rm active}}{n_{\rm eff}}.
   \]

   默认配置为约 `1.04520`，即约 4.52% 的归一化/相近折射率近似差别。这里不是发现某个 Python 因子抄错，而是说明“照论文各式”也不等于“得到任意异质波导下的严格守恒速率对”。本轮未暗中重定义 U 或改式 (10) 来凑守恒；若要改，应从同一电磁能量、模式增益与活性体积定义重新推导整套方程。新 Yb:YAG 速率使用独立的 `qE/qGain`，不能照搬这一半导体近似。
4. `current_ratio` 实际是 `I/I_ref`。配置历史字段虽名为 `threshold_current_A`，输入论文 0.7 A 不代表当前理想几何模型已独立得到同一阈值。本轮修正了相应 API 解释，绘图已用 `I_ref`。
5. 对非正交/近简并模，冷腔独立阈值和阈值差不能证明激射后单模；也不能将空间积分相干投影里消失的一条谱线判为没有该模式。局部探针非相干 FFT 和完整已表示频段有助于诊断，但仍不是总出光光谱。

## 8. 支持模块与历史代码覆盖边界

`config` 负责单位符号、被动输入和显式扩散稳定性验证；`injection` 负责参考电流的面积归一化；`io/run_output` 负责数组/来源保存；`cli/reproduce` 是历史标定入口；`plotting` 是显示。`fabrication` 只是周期几何与假设工艺规则，采样椭圆边界和圆角曲率需几何收敛，周期相同扰动不等于整片随机粗糙散射。Pareto 筛选改变保留哪一个器件，不改变某个器件的物理方程，但会受目标定义和漏模影响。

全 Python 风险扫描会列出限幅、拟合、代理、插值和异常捕获语句。它只能定位审查位置，不能凭关键字判定一个 `clip` 必定错误：例如几何线段投影 `clip(0,1)`、Stokes arcsin 的舍入保护、绘图 log-floor 都有合理用途；对密度、功率或本征值的实质裁剪则可能隐藏非物理解，需本轮这样的独立反例。
