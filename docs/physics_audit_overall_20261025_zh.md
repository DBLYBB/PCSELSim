# PCSELSim 全仓物理审计总览（2026-10-25）

**当前不能把本程序称为“所有代码完全按论文、算法不含任何物理近似、已验证真实器件可行”。** 本轮盘点全仓源码与物理配置，对主要光学、有限腔、半导体和 Yb:YAG 速率核心作公式/关键路径核对，并发现和修复了真实的输入护栏、模式筛选及能带转换问题。全仓清单覆盖不等于每个历史和探索脚本都完成了全分支逐式认证；未深审部分在逐文件记录中明确保留。

较准确的定位是：**有文献推导和独立极限基准支撑、适用条件公开的研究型近似工具。** 可信度来自公式、单位、原方程残差、独立解析基准、能量预算和可追溯输入共同支撑，而不是来自“代码跑完”或“测试数量多”。

## 3. 本轮修复的物理与算法问题

| 问题 | 物理影响 | 当前处理 |
|---|---|---|
| 固定实际频率下的 native 能带重复加入失谐 | 频率轴原点错误，部分场合还缺平方失谐导数的 `β0/βref` 因子 | 改用正确背景失谐与导数；影响能带图频率转换，不改冷腔 C 或阈值 |
| 将实质负辐射本征值 PSD 投影为 0 | 可把无效增益通道伪装成被动无损通道 | 只容许相对矩阵尺度的浮点舍入清理；大负值失败 |
| 未检查 Hermitian 化前的大偏差 | 可能将实现或不适用输入的大误差“对称化”掉 | 理论封闭项先检查，只有舍入误差可清理 |
| 几何接受复介电但后续取实部/封闭 Hermitian | 可能静默删除吸收物理 | 当前不支持的复介电、金属输入明确拒绝；不伪造吸收算子 |
| Heun 载流子阶段显著负值截为 0 | 可能掩盖强受激耗尽下未解析的时间步 | 分阶段有限性/正性检查，实质负值失败，要求减步或子步 |
| 辐射功率二次型负值全部截为 0 | 可能把非被动输入显示成零输出 | 相对 `||C||·|Φ|²` 尺度拒绝实质负值 |
| 多个扫描入口用过宽极点簇及高重叠去重 | 被动非正规算符的不同近共线模式可能被删除，虚增模式间隔 | 统一复本征值/子空间身份；旧 YAG 补模先闭频再判身份 |
| 旧 YAG 精细网格重闭频仍用高重叠去重 | 不同 TE 族或不同近共线极点可能被误合并 | `refine_ybyag_saved_poles` 同时核对实际频率、TE 族、C 和复极点身份 |
| 半导体未饱和波长漂移以相折射率作分母 | 丢掉模型已保留的导模色散 | 小信号诊断改为 `Δλ=λΔneff/ng`，用独立色散共振根验证；不改实际闭频结果 |
| 旧集总局部均匀泵的参考面功率被叫作入射功率 | 厚样本可能体积供能超过单面参考功率，混淆实际泵边界 | 明确局部供能/光学厚度及参考面定义；新研究使用实际输运 |
| 旧 YAG 动态返回结果直接裁反转/光子范围 | 可能把坏积分输出画成合法状态 | 原始已接受状态先检查，实质越界/负值拒绝；有效域公式不改 |
| 来源快照未纳入 `.json` 配置 | 可丢失实际优化几何和材料输入的来源约束 | 新快照补全 JSON/YML；不回写历史 SHA |
| 标定/人工辐射示意入口缺显式运行提示 | 易把拟合或人为孔径图误认作器件预测 | 增加明确警告和入口说明；保留历史追溯 |

这些修复不是为了让图更像论文，也没有删除高阶耦合来拟合原图。反例覆盖了实质负辐射、非实介电、负 Heun 阶段，以及满足被动性但本征向量重叠大于 0.99999 的不同复极点。

## 4. 哪些旧数值保留，哪些结论不能沿用

四个正式 300 μm 案例在其原始高精度参数下重新生成 C，并对冻结场读回：C 和材料阈值相对差均为 0，频率闭合残差仍在原验收范围内。证据为 [四腔光学重建](../results/current/physics_audit_20261025/optics/formal_optical_rebuild_after_guards.json)。这说明新护栏没有改变这些合法输入的光学值；它是同源参数重建，不是独立 Maxwell 认证。

继续保留：原始几何、复场、材料阈值和历史运行 SHA；不将新注释或新代码哈希写回旧仿真冒充原运行。

必须限制或补算：

1. **旧 native 固定频率能带图应按修正原点重画。** 不能把它的旧频率轴原封不动当成新模型输出。共同的频率平移/线性比例不会自动修复文献 AB/BC 间隔比，因此原文失配仍在。
2. **旧三角搜索需按新去重规则重新挑战近简并候选。** 旧结果的已保留模式仍是真实求得的候选，但“最近模式间隔”只对当时搜索并保留的集合成立。本轮没有悄悄重写为全谱认证。
3. 旧集总/标定/人工孔径及 `legacy_upwind` 截距路径不参与新正式几何排名。历史代码仍可用于回归/示意，不表示已经全部升级为正式预测后端。
4. Γ 点每族一态与同一 A 族的多个高阶横模是不同对象。论文 Fig. 2(d) 的 A 族序列还不能由每族各一张单瓣图声称已复现；真实 SEM 三维孔形和原始 C 数值仍缺失。
5. 新 YAG 泵浦输入—输出和尺寸阈值研究另开目录，既不覆盖旧文件，也不凭新代码反向提高旧结果的证据等级。

## 5. 两项不能隐藏的归一化近似

### 5.1 固定实际频率的近 Bragg 替换

Inoue A10 使用以晶格 `β0` 为基准的群速度和增益投影；当前导模接口用真实 `βref=k0 n_eff` 的 `n_g` 和 `qGain`。Bragg 点完全一致，离开 Bragg 后有 `s=βref/β0` 的差别。

四个正式案例的 s 分别约为 1.00987、0.99063、0.99740、0.99879，即约 +0.99%、−0.94%、−0.26%、−0.12%。这些量级不能被忽略后仍称“全式严格相同”，小于该尺度的微小优势也不宜过度解释。详见 [近 Bragg 范围记录](../results/current/physics_audit_20261025/optics/near_bragg_normalization_scope.json)。

本轮没有只改 `n_g`、损耗或 `qGain` 中的单一因子。取消该近似必须统一空间衰减、时间群速度、电磁能量和材料增益定义，并重新用能量及独立电磁基准验证。

### 5.2 半导体场—载流子受激能量交换

当前半导体把 Inoue 正文 (10) 的活性光子密度/受激项和 A10 的模增益同时照入。若用总场能量 `2ε0 n_eff n_g Σ|Φ|²`、每次受激跃迁 `ℏω` 做控制体积核算，则

\[
P_{\rm field,gain}/P_{\rm carrier,stim}=n_{\rm active}/n_{\rm eff}.
\]

默认配置约为 1.04520，即约 4.52% 的相近折射率/归一化近似。它不是某个 Python 因子误抄，而是说明“与论文各式对应”本身也不足以保证任意异质波导下的严格守恒速率对。本轮公开这一限制，未擅自改写原式凑守恒。

Yb:YAG 新空间速率和脉冲模型独立区分 `qEnergy`、`qGain`、真实活性体积与光子库，不直接迁移这套半导体近似。

### 5.3 三角特征网格与方形边界的取整误差

名义方形物理边界相同，不意味着不同斜网格具有完全相同的离散边界。新增 [方形掩模审查](../results/current/physics_audit_20261025/triangular_square_mask_review.json) 显示，这不是一个可简单归为“奇偶”的误差：特征链长度和节点控制面积会随网格对齐发生跳跃。

例如 L=200 μm 的 N25/N26 控制面积误差约 −0.27%/+2.58%，斜向中央链弦约 228/234.62 μm，而连续方形弦长约 230.94 μm；对应同一近似分支的材料阈值变化约 −4.31%，共同内部复场重叠约 0.99948。N26/39/52/65/91 都是 13 的倍数，沿这一对齐序列的收敛不能充分采遍不同边界取整相位。

对正式 300 μm 三角 YAG 已额外求 N53/N64 的原始 K/M 有限场：冻结各模原 C 和波长时，首模阈值估算分别比 N52 高约 0.31%/1.53%。随后 N64 的两条原分支又完成实际频率闭合：g₁=7.59672、g₂=8.50775 cm⁻¹，较 N52 分别高约 1.5265%/1.5546%；跟踪两模间隔约 11.992%，波长为 1030.01456/1030.04082 nm。原 K/M 相对残差不超过 8.8×10⁻14，频根残差不超过 1.56×10⁻5 /m。见 [非对齐网格实际闭频](../results/current/physics_audit_20261025/triangular_nonaligned_grid_challenge/summary_closed.json)。

这是两根已知分支的精度挑战，**仍不是完整低阈值谱或远场圆度鲁棒性认证**。没有按面积比例缩放原阈值来凑“修正值”，生产离散器也没有为得到较优阈值而改变边界。

因此，C 和阈值同源读回不变，与物理尺寸/网格收敛是否足够是两种不同的证据。涉及百分之一量级的比较应把这一不确定度公开。

## 6. YAG 速率与泵浦仿真的审计约束

现有空间 Yb:YAG 模型保留泵浦吸收、泵浦受激发射、激光再吸收、上能级寿命、受激耗尽及多模式共享反转。不同模式使用自己的波长/权重/损耗，并共同作用于同一反转；不能把每个模式独立泵浦算出的输出直接相加。

本轮对两种晶格、三种泵几何/程数、随机光子态共 18 组 32 模系统做独立控制体积核算：激发数/光子数平衡相对残差最大约 `3.82×10⁻13`，能量平衡约 `8.24×10⁻13`。这说明这些离散速率和泵预算相互一致，不证明输入截面、加工损耗或热模型真实。

解释新仿真必须保留以下边界：

- **外部泵功率、内部首次入口功率、吸收泵功率、向上激光输出是不同量。** 多程循环光不能被重复计作新的外部泵输入。
- 薄有源层侧泵的低条件阈值假定光已耦入窄边；真实聚焦/波导入射耦合尚未设计。顶泵则必须使用实际薄层吸收路径，不能沿用侧向长路径。
- 理想 20 程及每程返回效率是条件泵回收模型，不是已制造并验证的回收系统。
- 原型光谱常数来自材料文献/名义设定，并非当前 500 nm 加工薄膜的完整实测谱。互易/热能级配分函数能约束吸收—发射比，不能代替完整截面线形。
- 尺寸改变必须重新计算有限腔损耗和频率，不能从一条 300 μm 模式按 `1/L` 直接外推。本轮新研究的实际尺寸传入链已核对；有界粗谱/细网格挑战仍不等于完整模式普查。
- 小腔即使减小活性体积，也可能因边界损耗使所需材料增益超过泵浦反转上限；“体积小”不自动保证低阈值。
- 新脉冲输出能量使用单模均匀反转近似；没有因其通过能量预算便认为已解决实际空间多模、脉冲温升、损伤和锁模。
- 输入脉冲能量必须同时报告脉宽和波形。CW 功率阈值不能不加条件地改称脉冲能量阈值。
