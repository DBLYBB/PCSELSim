# Yb:YAG-PCSEL 新入口：设计、实跑与不能省略的限制

本轮保留所有原有半导体物理模型，独立实现晶体导波/底镜/空间增益迁移。
结论是**找到值得进一步验证的 CW 可行性候选**，不是已经证明可加工、稳定单模或超快的器件。

## 1. 点哪个文件

在 PyCharm 右键 `scripts/run_ybyag_pcsel.py` → Run。顶部参数区可改波长、晶体厚度、
孔填充率/位置、上下波导层、DBR材料/对数、器件大小、损耗、掺杂、截面、泵强度和网格。
修改 `STEPS` 控制输出；依赖的核心解算仍会执行。默认每次新建时间戳目录，不覆盖旧图片。

```powershell
python scripts/run_ybyag_pcsel.py --quick --only 01_structure 03_finite_modes 05_spatial_gain
python scripts/run_ybyag_pcsel.py
```

`--quick` 仅烟测。正式入口不会运行旧 YAG 的手填损耗或旧平均场程序。
主程序先构建同一个光学 C，再求有限模与输出，再将损耗、纵向权重和实际包络传入空间速率方程。

## 2. 当前具体堆叠

自上至下：

| 部件 | 候选参数 | 用途 |
| --- | --- | --- |
| 空气 | n=1 | 顶部出射端口 |
| SiO2 上包层 | 300 nm，假设 n=1.45 | 透明包层，不是顶镜 |
| 未图形化 SiN 上波导 | 245 nm，假设 n=2.00 | 把部分模场拉向表面 PC，不提供额外纵向激光反馈 |
| 被动 YAG 图形层 | 300 nm，YAG n=1.8154，SiO2 填孔 | 二维面内反馈；与增益晶体区别明确 |
| Yb:YAG | 8 µm，n=1.8166，名义10-at.% | 提供准三能级晶体增益 |
| SiO2 下导波隔离层 | 2 µm | 导波与底镜的低阶模隔离 |
| 独立 Ta2O5/SiO2 DBR | 16对，n_H=2.10，n_L=1.45，1030 nm λ/4 | 反射向下辐射，改变上下输出相位/比例 |
| 下半无限介质/待设计热沉 | 光学 n=1.8154 | 目前只规定光学端口；热结构尚需设计 |

YAG/Yb:YAG折射率参考1029 nm的原始陶瓷实验；该实验并非本层栈，也不证明本薄晶体PCSEL。
[Wang 2016 原文](https://www.nature.com/articles/srep31289)。膜的实际 n/k 和工艺验收见
[材料文档](ybyag_waveguide_materials_20261008_zh.md)。

晶格为周期约566.128 nm的正方双圆孔，总填充率0.10，小孔面积份额0.42，两孔相对位移
dx=dy=0.45a。孔内不是空气，而是SiO2；填充/平坦化后沉积无图形上波导是候选工艺，
未证明300 nm被动YAG层加工/键合良率。器件是1 mm边长的大孔径薄晶体面发射器件，
不能把“微腔”理解为只支持一个纵向模的小微盘。

采用940 nm双端边缘泵，避免假设普通1030 nm λ/4 DBR同时全透940 nm。
每侧内部入口2e5 W/cm²，按1 mm×8 µm边面积是16 W/侧、共32 W；
外部功率还要加耦合损失。尚未证明实际8 µm窄边可实现这样的均匀泵入。

## 3. 方程与模块的对应

1. `hybrid_vertical.py`：与旧TE离散同一标量Helmholtz方程，改用三对角本征求解并显式查看多纵向族。
   低阶模忽略远处DBR的导波反馈，必须逐模检查倏逝返回量，不能推广到所有高阶模。
2. `stratified_optics.py`：平面散射网络、有限底镜复反射、出射Green及上下通量。
   [完整推导](stratified_optics_derivation_20261008_zh.md)说明坐标、TE/TM变量与时间约定。
3. `reflector_cwt.py`：Liang四波和高阶代数，横向Green加入真实层状反射；
   `Im(Crad)=L_up+L_down`，无需凭反射率人为乘二。高阶纵向局域介电近似仍保留，
   不是完整三维矢量Maxwell模型；开放高阶辐射/吸收膜需要进一步扩展，程序明确拒绝。
4. `custom_analysis.py`：复用半导体的开放有限区域冷腔问题和复杂矢量远场，不移植半导体载流子方程。
5. `ybyag_spatial_rates.py`：准三能级再吸收、饱和泵传播、局部反转耗尽与一个选定模的光子库。

对均匀YAG有源层，

\[
g(z)=N_T[\sigma_e f(z)-\sigma_a(1-f(z))],\quad
q_{gain,i}=\frac{n_{YAG}}{n_{eff}}\int_i|\Theta|^2 dz
=\frac{n_g}{n_{YAG}}q_{energy,i}.
\]

有源权重不强行归一到1。空间烧孔使用同一有限模沿y积分、保守投影到x泵单元后的权重；
局域激发耗尽与同一个模态光子库守恒。再吸收不能又加进被动host吸收重复计数。

采用最细网格原始损耗作为较保守的数值门槛：

\[
g_{modal,th}=2\alpha_{raw}+\alpha_{internal,power}.
\]

但这不表示模型误差已被界定；迎风数值扩散仍在其中，不能把全部“other cavity loss”当材料发热。
速率方程是CW稳态、x-z反转与y积分投影，不是共享反转的全空间多模竞争或超快瞬态。

## 4. 当前正式实跑

完整结果：`results/ybyag_crystal_pcsel/20261008_164124_099495/`。
截断D=6，纵向5 nm，面内N=17/25/33；最细场、原始损耗和外推诊断分别保存。

| 量 | 条件计算值 |
| --- | ---: |
| Bragg参考波长 | 1030.0 nm |
| 有效/群折射率 | 1.8193765 / 1.8744618 |
| 有源能量/增益权重 | 0.454292 / 0.468761 |
| PC的 \|Theta\|² 重叠 | 0.240731 |
| TE0族最小原始损耗保留模 | C；近简并D，不能因此称稳定单模 |
| 所选模总原始功率损耗 | 4.46625 cm^-1 |
| 未激射泵分布下模态增益 | 10.41261 cm^-1 |
| 该分支内部泵阈值 | 约2.268 W，即默认32 W的0.07087倍 |
| 默认泵下计算向上/向下功率 | 约0.7760 W / 3.78 µW |
| 向上占垂直输出份额 | 99.9995%，不是总泵效率，也不是严格零下输出 |
| 吸收泵 / 量子亏损热预算 | 约4.4743 W / 0.3910 W；未解温升 |
| 所选单模条件远场 | 亮中心；椭圆率约1.003，全径RMS约0.0838° |

远场统计的轴向窗口约±0.974°；0.5°内能量约99.979%是对该窗口归一化，
不是全空间收集效率。`04_beam_zoom_checked.png`仅把显示窗口缩到±0.2°，不更改统计或物理光斑。
它修正了原zoom图过长标题的裁切；原图保留，展示修补另有JSON记录。
所有这些功率是**透明膜/名义截面/单TE族冻结Bragg模型的计算分支**，不可当成实物输出承诺。

增厚/盖层扫描与底镜间距扫描分别在CSV中：增厚可增加泵程长但不自动增加表面PC重叠；
盖层过厚会形成无增益层主导模；底镜间距改变Crad相位，因此最高反射率并不等于最好出光。
本轮扫描4/8/15/30/50 µm和若干盖层厚度，是趋势诊断，不是联合阈值/工艺的全局优化。

## 5. 目前最关键的未完成验证

隔离导波近似在1030 nm有19个TE族，TE1–3在同一周期下也有条件增益门槛；
真实截面需按各自波长/温度重测。部分高阶族不能继续忽略DBR负载。
独立检查见 [多纵向模与吸收审计](ybyag_independent_checks_20261008_zh.md)。

此外，Bragg参考波长不等于有限模实际激射波长。频率一阶换算
`omega_mode≈omega_B+(c/ng)delta`；厚层中的反射相位可能随这几纳米偏移显著变化。
当前CWT在Bragg频率冻结纵向场/Green，需检查C(omega)敏感性并进一步解频率自洽本征问题。
这和跨波长增益谱缺口都禁止把上述功率/模排序宣称为定量预测。

正式D6/N33结果的独立复算已显示：C模按群速换算约1026.451 nm；固定原有模场重算
该频率的辐射Green，Crad矩阵相对变化约20.52%，向上功率损耗约降低20.07%。
这不是完整自洽新解，也不能据此直接修正0.776 W；它说明频率冻结误差不可忽略。
CSV/JSON及归档复算入口见独立检查文档第7节。

膜吸收可使TE0较其他纵向模更吃亏；低吸收化学计量SiN有原始证据，但不能沿用1550 nm
波导规格或把某种膜的1064 nm吸收直接当本批1030 nm数据。优先实测低吸收SiN，亦比较
低吸收Ta2O5上波导；换材料必须重算厚度、场、C与损耗，不能仅换名字。
随后需共享反转多模竞争、频率/材料色散自洽、开放边界全波核查、热/应力与泵耦合验证。

## 6. 看哪些输出

- `summary.json`：参数、层序、source SHA256、模损耗、统计窗口、增益门槛与能量预算。
- `run_status.json`：只有正常完成才写complete，不能把失败残留目录当正式结果。
- `optical_core.npz` / `finite_modes.npz`：C分量、上下损耗算符、纵向场、各有限复场和收敛数据。
- `04_mode_atlas.png` / `04_far_field_*.png` / `04_beam_zoom.png`：包络、晶胞场与条件远场。
- `05_spatial_gain.npz` / `05_inversion_pump.png` / `05_pump_scan.json`：空间反转、泵耗尽、包络权重和功率预算。
- `06_thickness_cap_families.csv` / `06_spacer_phase.csv`：多族重叠和底镜相位诊断，不作阈值排行榜。

单模CW、被动调Q、增益腔自锁模、独立Kerr微腔脉冲是不同任务。
[超快路线文档](ybyag_ultrafast_routes_zh.md)给出证据边界与下一阶段所需方程；本轮没有声称完成飞秒仿真。
